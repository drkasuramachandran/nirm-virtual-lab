# Source basis used for this updated package

This package uses the following supplied source material as its program basis:

1. Executive Development Program curriculum PDF: Non-Ionizing Radiation in Medicine.
2. One-month certificate program PDF: Non-Ionizing Radiation in Medicine — From Fundamental Physics to Biomedical Imaging, Therapeutics and Instrumentation.
3. Supplied Emergent/Vibe Coding implementation prompt for the Virtual Biomedical Optics, Radiation & Instrumentation Laboratory.
4. Supplied `files.zip` containing the existing `main.jsx` and `styles.css` curriculum/UI implementation.

The four-week / twenty-day sequence in the application follows the supplied curriculum. The interactive labs are educational simplified models and should not be interpreted as clinical or diagnostic calculations.
